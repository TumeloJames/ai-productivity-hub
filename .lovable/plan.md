# Personal Productivity Dashboard Refresh

## Goal
Restyle the existing assistant with the requested neutral and sage palette, then turn the dashboard into a responsive personal usage overview. All AI tools and their existing workflows remain unchanged.

## What will change
- Replace the purple theme with the requested warm-white background, white surfaces, charcoal sidebar, dark text, grey borders, and muted sage accents.
- Keep styling minimal: no gradients, restrained shadows, 12–16px corners, and more whitespace across every screen.
- Add a larger dark welcome heading above the existing tagline; keep the tagline smaller and regular weight.
- Add four personal KPI cards: AI Tasks Completed, Emails Generated, Research Tasks, and Chat Interactions.
- Add a seven-day productivity activity chart, an AI tool usage chart, and a chronological Recent Activity list.
- Keep tool links and Responsible AI guidance already present on the dashboard.

## Usage tracking
- Add a small browser-storage utility shared by the email, research, chat, and dashboard screens.
- Record only successful actions: generated emails, completed research analyses, and submitted chat messages.
- Derive totals, seven-day activity, tool distribution, and recent activity from those real local events.
- Update the dashboard immediately when usage changes in the same browser tab and safely handle empty or unavailable storage.
- Show honest zero/empty states until the user performs actions; no fabricated workplace or company metrics.

## Validation
- Check all four screens at desktop and mobile sizes.
- Verify each successful tool action increments the correct metric and appears in recent activity.
- Confirm the app still builds cleanly and existing AI interactions remain functional.
